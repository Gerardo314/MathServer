Follow the steps to successfully to compile and execute the program:

1. Open a new terminal and move to the src folder: 
cd src

2. Enter the following command to compile the program:
make          

3. Start the server:
make run-server 

4. Open a new terminal and move to the src folder(cd src). Enter the following command to run the client:
make run-client
Repeat this step everytime you want to run a new client.

5. Remove all the compiled files:
make clean
